# Engram Documentation

Engram keeps your AI conversations word for word and makes them searchable
from every AI app you use.

The full documentation lives on the website: **[getengram.app/docs](https://getengram.app/docs)**.
This folder holds the developer pages that have no counterpart there, or that
go into more detail. See [README.md](./README.md) for why.
